# RAMP: RTX 3050 로컬 파일럿 결과

2026-10-17 · RTX 3050 8GB · 시스템 RAM 8GB · FunctionGemma 270M · seed 0

## 핵심 결과

공유 가중치로 줄인 모델의 성능을 재귀 깊이로 회복하는지를 확인했다. 200스텝 파일럿에서는 깊이 36이 함수 선택을 한 문항 더 맞혔으나, 모든 RAMP 조건에서 인자까지 정확한 호출은 0/8이었다. 이 결과만으로 RAMP 전체 가설을 기각하거나 성능 회복을 주장할 수 없다.

| 깊이 / rank / 공유 가중치 | 함수 선택 | 정확한 호출 | 학습 샘플 확인: 정확한 호출 | 학습 시간 | 학습 중 최대 할당 VRAM |
|---|---:|---:|---:|---:|---:|
| 원본 교사 | 7/8 | 7/8 | — | — | — |
| 18 / 4 / 고정 | 1/8 | 0/8 | 2/4 | 90.3초 | 710 MiB |
| 36 / 2 / 고정 | 2/8 | 0/8 | 1/4 | 162.3초 | 967 MiB |
| 36 / 2 / 학습 | 2/8 | 0/8 | 2/4 | 176.0초 | 1181 MiB |

VRAM은 PyTorch가 학습 구간에 할당한 텐서 메모리의 최대값이다. CUDA 컨텍스트, 다른 앱, 예약 메모리를 포함하는 nvidia-smi 전체 사용량과 다르다. 시간은 동기화 후 측정한 학습 루프이며 모델 로딩·생성 평가 시간은 제외한다.

## 비교 조건과 적용 방법

- 학습 16개, 평가 8개(4종 함수 × 2문항), 별도로 이미 학습한 4개 문항을 확인했다. 각 실행은 처음부터 200스텝, 같은 seed와 섞인 샘플 순서를 사용했다.
- 두 고정 조건은 어댑터 949,248개, 전체 174,295,680개로 동일하다. rank를 4→2로 줄였으므로 순수한 깊이 단독 비교가 아닌 고정 파라미터 예산 비교다.
- 공유 가중치 학습 조건은 전체 크기는 같지만 학습 대상이 949,248→6,522,880개로 늘어난다.
- LoRA A는 각 깊이에서 Kaiming uniform, B는 0으로 초기화했다. alpha=2×rank를 사용했다. [PEFT의 표준 LoRA 초기화](https://huggingface.co/docs/peft/en/developer_guides/lora)
- AdamW, 어댑터 학습률 3e-4, 공유 가중치 학습률 3e-5, weight decay 0.01, gradient clipping 1.0을 사용했다. 초기 5% 워밍업 후 코사인 학습률 감소를 적용했다. [Transformers 스케줄러](https://huggingface.co/docs/transformers/en/main_classes/optimizer_schedules)
- BF16 연산·FP32 학습 가중치·BF16 교사 타깃 보존을 사용했다. NaN/inf 손실 또는 기울기에서 즉시 실패하도록 했다.
- PyTorch SDPA를 사용하고 GPU 학습·생성 검사를 통과했다. 별도 eager 대비 속도 향상률을 실측한 것은 아니다. [PyTorch SDPA](https://docs.pytorch.org/tutorials/intermediate/scaled_dot_product_attention_tutorial.html)
- 모델 리비전은 39eccb091651513a5dfb56892d3714c1b5b8276c로 고정했다. 교사 계산은 모델·입력·평가·정밀도 키를 검사한 뒤 재사용했다.

## 평가 기준

함수 선택은 출력에서 `call:` 뒤의 함수 이름이 정답과 같은지 평가했다. 정확한 호출은 `<start_function_call>...<end_function_call>` 구간이 토크나이저로 만든 정답 문자열과 정확히 같은지를 평가했다. 인자 순서·표현이 다른 의미상 동등한 호출도 불일치로 셀 수 있는 엄격한 문자열 기준이다.

## 해석과 다음 우선순위

호출 형식을 갖춘 출력은 고정 조건에서 각각 8/8, 7/8이었으나 함수 선택과 인자 연결이 약했다. 낮은 teacher-forcing 손실만으로 생성 능력 회복을 판단해서는 안 된다.

다음에는 동일 샘플을 더 반복하기보다 학습 문구·인자·함수 조합을 다양화하고 별도 검증/시험 세트를 고정하는 것이 우선이다. 이후 18/36을 같은 학습 조건·연산 예산으로 비교하고 여러 seed에서 재확인해야 한다. 현재 평가 8개와 seed 하나로 일반화를 주장할 수 없다.

이 실험은 GPU 소프트웨어 파일럿이다. SRAM 상주, 실제 오프칩 트래픽, FLOPs, KV 캐시가 있는 추론의 성능은 측정하지 않았다.
